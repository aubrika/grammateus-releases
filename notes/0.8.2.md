- **A reading is one item.** When you import a PDF, paragraphs that follow one another (the verses of a reading, the parts of a long prayer) now come in as one text item, so you can edit them together. To join two text items in a bulletin you already have, choose the first and press **Join with the text below**.
- **Keep on one page.** A text item can now be kept on one page: instead of being split between pages, it moves to the next page whole. Importing a PDF does this for the Lord's Prayer.
- **The dismissal page** of an imported bulletin is now part of the service, with its note in the grey side column like every other note.
- **More room for music.** "continued on the following page…" is now printed below the column, beside the page number, so music can run further down the page. Bulletins you have already saved may break onto pages a little differently, so look them over before printing.

To install it fresh, see [which file to download](https://github.com/aubrika/grammateus-releases#which-file-to-download).
