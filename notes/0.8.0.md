- **Importing a PDF is much more faithful.** A bulletin brought in with **Import PDF…** now keeps the font it was set in, the size of its music and pictures, pictures set beside text, lines drawn across the page (such as under a heading), grey boxes, and the layout of the back page. Music that was cropped in the PDF is no longer printed twice. An imported bulletin now usually takes as many pages as the original.
- **Grey behind text, and line spacing.** A text item or a column can now have grey behind it, like a side note, and a text item can be given its own line spacing.
- **Smaller PDFs.** The PDF Grammateus makes no longer stores each picture twice, so it is often about half the size. It still opens again in Grammateus exactly as it was saved.
- **A little more room on each page.** The text and the grey side column now run to half an inch from the bottom of the page, with the page number just below. Bulletins you have already saved may break onto pages a little differently, so look them over before printing.

To install it fresh, see [which file to download](https://github.com/aubrika/grammateus-releases#which-file-to-download).
